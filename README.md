# Sauci - Pasta Brand Landing Page

This repository contains the source code for the official landing page of Sauci, a premium pasta brand. The website provides information about Sauci, links to order food, a way to provide feedback, and connects to our social media presence.

## Purpose

The main purpose of this website is to:

*   Introduce Sauci and its offerings to potential customers.
*   Provide easy access to order Sauci pasta through Zomato and Swiggy.
*   Collect customer feedback through a dedicated form.
*   Offer links to Sauci's social media profiles.
*   Enhance brand visibility and customer engagement.

## Key Features

*   **Brand Information:** Displays a description of Sauci, its operating hours, and location (HSR, Bengaluru).
*   **Ordering Links:** Direct links to Sauci's Zomato and Swiggy pages for convenient ordering.
*   **Feedback Form:** A link to an external form for customers to provide their valuable feedback.
*   **Social Media Integration:** Links to Sauci's Instagram, X (formerly Twitter), and WhatsApp.
*   **Thank You Modal:** A special pop-up message with a celebratory animation for users visiting via a `utm_source=thank_you` link, typically after placing an order.
*   **SEO Optimized:** Includes meta tags and structured data (Schema.org) for better search engine visibility.
*   **Analytics:** Integrated with Google Analytics for tracking website traffic and user engagement.

## Technologies Used

*   **HTML:** For the structure and content of the website.
*   **CSS:** For styling and layout.
*   **JavaScript:** For interactive elements like the thank you modal and dynamic content.

## Viewing the Website

To view the website, simply open the `index.html` file in any modern web browser.
